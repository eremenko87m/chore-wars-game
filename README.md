# Chore Wars — GitHub Pages project

Ready-to-upload static website for the Grade 4 A1+ lesson game.

## Upload to GitHub
Upload the CONTENTS of this folder to the root of your repository:
- index.html
- .nojekyll
- assets/
- README.md

GitHub Pages should publish from the `main` branch and `/ (root)`.

## Important
The game logic and CSS are embedded inside `index.html`, so there are no separate `game.js` or `styles.css` files required.
